# 🎮 Auto-Vote-Rating

> Automated voting extension for game server rating sites

[![Version](https://img.shields.io/badge/version-1.1.1-green.svg)](https://github.com/JustMordeckai/Auto-Vote-Rating/releases)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## 📋 Overview

Auto-Vote-Rating is a browser extension that automates voting for your favorite game servers across 100+ rating platforms. Never miss a vote again with intelligent scheduling, cooldown detection, and multi-site support.

## ✨ Features

- 🤖 **Automated Voting** - Schedule votes across 100+ rating sites
- ⏰ **Smart Cooldown Detection** - Automatically detects when you can vote again
- 📊 **Statistics Tracking** - Monitor your voting history and success rates
- 🔕 **Silent Mode** - Vote in background without opening tabs
- 🌐 **Multi-Platform Support** - Minecraft, Discord bots, MMO games, and more
- 🔒 **Privacy Focused** - All data stored locally, no external servers

## 🚀 Installation

### For Chrome / Edge / Brave / Opera

1. **Download the extension**
   - Go to [Releases](https://github.com/JustMordeckai/Auto-Vote-Rating/releases)
   - Download the latest `Auto-Vote-Rating-v*.zip` file
   - Extract the ZIP file to a folder on your computer

2. **Load the extension**
   - Open your browser and navigate to:
     - **Chrome**: `chrome://extensions/`
     - **Edge**: `edge://extensions/`
     - **Brave**: `brave://extensions/`
     - **Opera**: `opera://extensions/`
   
3. **Enable Developer Mode**
   - Toggle the "Developer mode" switch (usually in the top right corner)

4. **Load unpacked extension**
   - Click "Load unpacked" button
   - Select the extracted folder
   - The extension should now appear in your browser toolbar

## 📖 Quick Start

1. **Add a Server**
   - Click the extension icon in your browser toolbar
   - Click "Add Server" or "+"
   - Enter the voting page URL
   - Configure voting settings (nickname, intervals, etc.)

2. **Start Auto-Voting**
   - Enable the server in your list
   - The extension will automatically vote at the optimal time
   - Check statistics and logs in the dashboard

## ⚙️ Configuration

### Basic Settings
- **Nickname**: Set your in-game username for voting
- **Silent Vote**: Vote in background without opening tabs
- **Timeout**: Page load timeout (default: 10s)
- **Vote Timeout**: Maximum time to wait for vote completion (default: 15min)

### Advanced Options
- **Custom Vote URL**: Add support for unlisted rating sites
- **Randomize Votes**: Add random delay between votes (anti-bot detection)
- **Debug Mode**: Enable detailed console logging
- **Priority Voting**: Vote on high-priority servers first

### Notifications
Customize when to receive notifications:
- ✅ Success notifications
- ⚠️ Warning notifications
- ❌ Error notifications
- ℹ️ Info notifications

## 📊 Statistics

Track your voting activity:
- **Total Votes**: Lifetime successful votes
- **Monthly Votes**: Current month statistics
- **Today's Votes**: Daily progress
- **Success Rate**: Vote success percentage
- **Error Count**: Failed vote attempts
- **Last Vote**: Timestamp of most recent vote

## 🐛 Troubleshooting

### Extension not working?
1. Make sure Developer Mode is enabled
2. Try reloading the extension (`chrome://extensions/` > Reload button)
3. Check browser console for errors (F12)

### Votes not being registered?
1. Verify the voting URL is correct
2. Check if the site requires manual captcha solving
3. Enable debug mode to see detailed logs
